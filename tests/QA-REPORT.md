# Terenska knjiga — QA report

Reviewed: `src/app.html` and `src/sw.js` at commit `f46905b`. **Status column: hardening pass on the merged app (branch from `6a1c963`), commits named per finding.** (line numbers refer to that commit; other engineers are editing `src/app.html`, so search by function name if lines have moved).
Method: full read of the source, an automated harness (`node tests/run.js`), and a walk-through of `docs/index.html` at 375×812 in a browser (every tab and every document of both packs, for all three seeded sites).

Severity: **critical** = can put a wrong fact into a legal report or lose field data in normal use; **high** = data loss, wrong data or a security hole under a plausible condition; **medium** = wrong or misleading output, or a real usability or accessibility barrier; **low** = polish.

Each finding with an automated reproduction has tests marked `xfail: 'F-nn'`. They report XFAIL while the bug exists and XPASS once it is fixed. When that happens, remove the marker.

**Note on the datum shift:** `MGI_SHIFT=[682,-203,480]` (l. 328) is a demo 3-parameter MGI 1901 → WGS84 shift. The tests check that it is applied in the correct direction and consistently (MGI→WGS adds the shift; an independent implementation agrees to < 1 cm). They **cannot** check that the values are right for BiH. A 3-parameter shift can be wrong by several metres. **Confirm the transformation (ideally the official 7-parameter or grid set) with BHMAC / FGU / RGURS before any coordinate goes into a submitted document.** Until then the UTM/WGS84 output for BiH sites should carry a visible "demo transformacija" note. GK coordinates read directly from the dosije are not affected.

## Test harness

`node tests/run.js [filter] [--verbose] [--strict]`. It uses Node built-ins only and pins TZ to Europe/Sarajevo.

- `tests/lib/harness.js`: extracts the app script from `src/app.html`, removes the IIFE wrapper and runs it in a `vm` context with a controllable clock, a fake DOM (form values derived from the rendered HTML), Map-backed localStorage, and an asynchronous fake IndexedDB with fault injection. Tests call app functions directly (`app.run('laneLen(site(),4)')`) or dispatch the app's delegated clicks (`app.click('adv',{l:'10',m:'1'})`).
- `tests/lib/geo-ref.js`: an independent reference for the geodesy (Krüger n-series TM, iterative ECEF inverse).
- `tests/fixtures/state-v2.json`, `state-v3.json`: real state shapes produced by running the v2 (`310b40c`) and v3 (`bc53ae8`) app versions from git history in the same harness.
- Suites: `01-geodesy`, `02-lanes`, `03-boxes`, `04-dates`, `05-documents`, `06-exports`, `07-storage`, `08-security-a11y-offline`.
- Exit code 1 only on FAIL. XFAIL = known defect (finding id in brackets), XPASS = probably fixed, remove the marker (`--strict` fails on XPASS).
